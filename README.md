# Zest

An orange-and-white music streaming app that runs entirely in the browser. Play songs, build playlists and albums, and add your own tracks.

## Features

- **Home, Search, Library, Create, Settings** navigation
- Player with play/pause, previous/next, seek bar, and volume
- Like songs and save them to your library
- Create playlists (with a public label) and albums
- Upload your own songs
- Settings for your name, accent colour, and autoplay

## Run it

No build step needed. Open `index.html` in a browser.

To host it free with GitHub Pages: go to **Settings → Pages**, choose the `main` branch, and save.

## Use your own music

The starter songs are demo tracks from [SoundHelix](https://www.soundhelix.com). To use your own, edit the `tracks` list near the top of the script in `index.html` and point `src` at your audio files or URLs. Only use music you have the rights to share.

## Known limits

- Uploaded songs last only until the tab is closed.
- "Public" is a label for now. Sharing playlists between people needs a backend.
